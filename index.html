Research Interests

Hardware–software co-design for prefetching

Existing hardware prefetchers are typically specialised for particular access patterns and make limited use of the rich program context available to compilers. My research aims to bridge this gap by combining compiler-derived knowledge of program intent with dynamic runtime information, enabling a more universal prefetching architecture that can capture a broader range of memory-access patterns, hide memory latency more effectively, and use hardware resources more efficiently than conventional fixed-function designs.

Memory Systems

Hardware prefetching, cache management, and memory-level parallelism.

Microarchitecture

Adaptive microarchitectural mechanisms for speculation and performance optimization.

Compiler Co-Design

Exposing static program knowledge across traditional abstraction boundaries and combining it with runtime learning to guide memory-system decisions.
